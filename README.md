# Sofía Residencial

MVP web para la gestión de reuniones, puntos a tratar, asistencia, quorum, minutas, acuerdos y planes de acción de Sofía Residencial.

## Objetivo

Centralizar el ciclo completo de administración vecinal:

**Necesidad → priorización → agenda → reunión → acuerdo → plan de acción → seguimiento → cierre**

## Tecnologías del MVP

- HTML, CSS y JavaScript puro para el prototipo.
- Google Sheets como base de datos inicial.
- Google Docs para minutas.
- Google Drive para documentos y evidencias.
- Google Forms para asistencia y propuestas.
- Google Calendar para reuniones.
- Google Apps Script para automatizaciones e integración.

## Uso local

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

## Alcance actual

Este repositorio contiene un prototipo navegable del MVP. Los botones y flujos simulan la experiencia esperada; las integraciones reales con Google Workspace se incorporarán en la siguiente etapa.
